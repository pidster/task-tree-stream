# Git

- Do not commit or push unless the user asks. Never force-push or rewrite history on `main`.
- When asked to commit: branch per piece of work unless told to commit on `main`; commit messages say why, not only what; end with the attribution lines the session requires.
- Never commit secrets, `.env` files, or `settings.local.json`.
- Before any destructive git operation, show the target state and confirm.
